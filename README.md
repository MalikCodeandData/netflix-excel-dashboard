# 📊 Netflix Titles Dashboard - Excel Project

## Overview

This project is an interactive Excel dashboard built using the Netflix Titles dataset from Kaggle. It showcases key insights about the content available on Netflix, using Pivot Tables, Charts, Slicers, and Excel formulas.

## 🔧 Tools & Features

- Microsoft Excel (365 - Mac)
- Pivot Tables
- Pivot Charts (Bar, Column, Pie)
- Slicers for interactivity
- Excel Table formatting
- Dashboard design

## 📈 Dashboard Insights

- 🎬 **Movies vs TV Shows**: Distribution of content types on Netflix
- 🌍 **Top Countries**: Countries producing the most titles
- 🎭 **Popular Genres**: Most common genres across all titles
- 🔞 **Content Ratings**: Breakdown by maturity rating (PG, TV-MA, etc.)
- 📅 **Titles Added by Year**: Trends of content added over time

## 💡 Key Findings

- Netflix has more TV Shows than Movies in recent years.
- Drama and International content dominate the genre distribution.
- The majority of content is rated for mature audiences (TV-MA, R).
- The USA, India, and the UK are top content-producing countries.
